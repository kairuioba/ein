# 一念 Ein 2.0.0 发布说明

## 这版的关键变化

- **任务式工作台**：新任务=新窗口；已完成任务只读，可「基于此新建」并只带已验收经验，不复制聊天；
- **验收闸门**：验收标准结构化；代码做确定性检查；**接入独立模型评审员**（一次性干净会话、逐字引文、失败不通过、通过才撤掉你的验收卡）；
- **项目内协同工作台**：一句话结论、团队状态、谁被谁卡住、待拍板、交接回执（接收/退回/重发）；
- **需要你**：统一口径、注意力分流（现在就要你/进收件箱/自动处理/归档）、稍后 24h 自动回流；
- **自我进化**：失败模式→改进提案→你采纳→维护机器人在隔离工作区改动→范围守卫+固定测试+独立评审→**你批准后才合并**，可回滚；保护文件（门禁/审计/权限）哈希锁定，进化改不到自己的护栏；
- **老板时间账本/晨报/站会/周复盘**：数字全部由代码生成，不靠模型叙述；
- **可靠性**：重启恢复、attempt 幂等、SSE 断线补全、审计覆盖手动批准与自动处理（自动批准永不计入自身信任）。

## 已知边界

- 模型评审只提供证据，最终由代码与你裁决；高风险仍会留给你；
- 阶段4 只允许改 `prompts/ templates/ docs/`（白名单），merge 必须你点；
- 手机端项目工作台以页面形式提供，桌面三栏是后续迭代；
- 自动批准会写审计，但「撤销后 14 天冷却」等信任规则仍在逐步积累真实数据。

## 升级/回滚

- 数据只增字段、不删不改旧字段；升级前建议备份 `~/.ein`；
- 回滚只需装回 1.1.3，新版本产生的文件会在旧版本中被忽略；已有任务/聊天/配置不丢。
