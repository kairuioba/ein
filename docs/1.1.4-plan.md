## 已确认产品规则（老板最终裁决）
- 新任务 = 新窗口（新对话页）。
- 旧任务窗口永久保留，员工可释放/复用，但不能把员工调度进新任务、不能动旧窗口。
- 相似任务的上下文可以分享，但只分享 Handoff 摘要（有界、只读），不搬旧对话全文。

## 与 Claude 评审后的落地细化（第 6 轮）
- 任务窗口：权威字段放会话侧 `conversation.folderId/role(main|worker)/botId/attemptId`；`folder.conversationId` 保留为主窗口指针（派生）。复盘按 `folderId` 查全部会话，不搬。
- Bot 归属：`bot.currentTaskId` 为唯一权威（原子 claim/release）；`folder.memberBotIds` 是派生索引。任务终态释放，旧会话随任务保留；终态任务的会话拒绝新派单（要续做就新建任务 + sharedFromTaskIds）。
- 上下文共享 v1：候选=已验收/同部门/同工作区；同 Bot 自动预选，其余负责人勾选；最多 3 源；只共享目标/产物引用/决策/验收证据/踩坑/未决；≤1500 tokens（单源≤600）；服务端校验部门隔离+敏感过滤；渲染带“仅供参考、须核实”声明；审计快照进复盘页。失败任务只贡献 negative 教训。
- 复盘 UX：已完成任务详情里的只读页：attempt 时间线、会话列表、产物 manifest、gate 证据、Handoff、上下文快照、人工备注；不进侧栏、不打扰日常。
- 顺序：C1 数据模型与归属强制 → C2 复盘读模型 → C3 上下文共享 v1；砍掉 LLM 自动复盘、向量选源、跨部门默认、reopen 旧任务、搬会话。
