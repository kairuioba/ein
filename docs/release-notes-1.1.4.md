# 一念 Ein 1.1.4 发布说明（草稿，未发布正式版）

状态：**候选版**。正式版发布需满足：①老板真机实测一轮无 P0；②升级/回滚验证通过；③GitHub Actions 恢复（当前计费失败）。

## 现在能做什么

- 每个任务一个独立窗口；任务完成后窗口只读，可点「基于此新建」接着做，不复制旧聊天；
- 侧栏能看到所有任务，点任务行打开窗口，点旁边的协同图标打开项目协同面板；
- **项目协同面板**：一句话结论、等待你拍板的事、谁被谁卡住、团队状态、异常；
- 交付前按你定的验收标准检查；不过关可「打回，重做」，重做会带着你写的那句话；
- 「需要你」收件箱按任务集中待拍板事项，可「通过，继续 / 打回，重做 / 稍后」；
- 简报页显示「今天要你花多少时间」和「公司在自我进化」的改进提案（采纳/不采纳/稍后）；
- 复盘、只读窗口、上下文继承（只带已验收经验，不带聊天记录）。

## 还做不到

- 系统不会自己改自己：自我进化目前只到「出提案 + 老板决定」；阶段4自修改只有安全规则，未开启；
- 手机端项目工作台目前是设计稿/mockup，不是已集成页面；
- 验收闸门 v1 以形式和事实检查为主，拿不准会交给你判断，不保证内容质量；
- GitHub Actions 计费修复前，自动化构建与正式版发布不可用。

## 建议怎么验

1. 新建一个真实小任务，走完「交付 → 需要你 → 通过或打回」；
2. 故意打回一次并写一句原因，确认重做时带上了你的话；
3. 在已完成任务窗口点「基于此新建」，确认旧聊天没有被复制；
4. 看简报页的 owner-time 数字是否接近你的真实感受。

## 已知限制

- 交接超时会升级（handoff_stuck），但「重发交接」目前需要回对话处理；
