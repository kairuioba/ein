# 一念 Ein 2.0.1 修复说明

## 这版修了什么

- **计划必须先经你确认**：派单计划生成后会先进入「需要你」，卡片上只有「确认开始 / 不执行」；你不点，团队不会开始干活，不会消耗模型额度。默认开启，可在设置里改；
- **同一个任务窗口只允许一个执行计划**：之前同一窗口可以再起第二个计划，两个计划并行抢同一份工作、重启后还会一起自动恢复；现在第二个计划会被拒绝并提示等待或先取消；
- **侧栏任务层级**（按你的要求）：展开任务 → 任务总控（跟你沟通的 bot）→ 项目负责人 → 一级部门（人数 + 在干什么）→ 点开部门看员工和当前在干什么；
- **去掉红色闪电**：侧栏不再出现 ⚡ 警告徽标，只保留中性的「需要你 N 件」；
- 计划确认卡在「需要你」里可直接处理，工作台确认后卡片自动消失。

## 升级/回滚

- 数据只增字段；升级前建议备份 `~/.ein`；
- 回滚到 2.0.0 仍可读；被本版拒绝的重复计划不会自动恢复。
