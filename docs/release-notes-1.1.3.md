# 一念 Ein 1.1.3 更新说明（草稿）

> 面向用户的一页说明，正式发布前随版本一起发布。分支：`fix/1.1.3-prep`（本地集成，未合 main）。

## 新增

- **Claude API 引擎**：设置 → 引擎里多一个「Claude API」，填自己的 Anthropic API Key 即可按量使用；Key 走系统加密存储、不回显，不会自动读取本机其它 Key。订阅版 Claude 的行为不变。
- **插话补齐**：pi、Grok API / OpenAI 兼容 / MiniMax 现在支持回合内插话；群聊输入框在机器人可插话时直接送进当前回合，不再一律排队。
- **维护岗模型选择**：下拉按 `云端`（OpenAI/GPT 系）/ `WorkBuddy`（全部模型）/ `引擎` 分组；打开时预选维护机器人当前保存的模型，不再误切引擎。
- **WorkBuddy**：默认模型改为 DeepSeek V4.1 Flash，移除含糊的「默认模型」占位项；旧 Bot 的选择自动迁移；ACP 回合固定真实 model id。

## 修复

- **macOS 每次启动弹「一念想控制此 Mac」**：启动时只做只读检查，不再主动申请辅助功能/屏幕录制；需要电脑控制时在设置页点「重试」再授权。
- **维护岗配置重启丢失**：源码路径 / 维护 Bot / 更新渠道现在会持久化，「开发版」渠道可以保持。
- **新 Bot 默认引擎**：不再落到还没保存 Key 的引擎上导致首条消息失败。
- **聊天工具步骤**：显示「运行命令」等短标签，原命令放悬停提示；失败只加一个小红标记，不再整条命令铺红。
- **记忆面板**：编辑器随内容增高，滚动不再被输入框吃掉、裁行。
- **侧栏**：悬停归档按钮不再压住时间/未读点。
- **Windows 开发版构建**：移除无效的 `-c.detectUpdateChannel=false`（此前会让 dev 构建失败）。
- **派单与公司层**：8 个审计缺口里 6 项修复（create_bot 规则、部门编制、会议室决议关联计划、重启「已完成」事件、无人值守状态过期、兜底计数口径），部门隔离与工作台加人做了最小修复，未完成部分见 `docs/dev-edition-plan.md`。

## 开发者/维护岗

- **派单计划更完整**：每个子任务现在固定带「边界（不做什么）/ 交付物 / 验收标准 / 验收人」，员工提示词和总控汇总都会引用；验收人缺省为总控。
- **「构建与发布」升级**：发开发版前会预检分支（是否已 push、分支是否带工作流、将构建的版本号），并显示 main 版本与最新正式版；点按钮后直接给出 GitHub 运行链接；开发版构建改为使用**该分支自己的 workflow 定义**，分支上的 verify/打包修复立即生效。
- 发布工作流新增 **verify 硬门槛**（typecheck / i18n / lint / 全量测试 / UI build），失败不发布；CI 增加 i18n 与 lint，`fix/**` 分支也会跑 CI。
- 双渠道：稳定版 + 滚动 `dev` 预发布；每次构建保留 `backup/v<版本>` 源码标签。
- 维护机器人手册更新：用中文叙述进度（复现→根因→改了哪些文件→测试结果），命令失败先用一句话解释。
