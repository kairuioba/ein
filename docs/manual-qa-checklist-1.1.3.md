# 一念 Ein 1.1.3：真机手动验收清单（10–15 分钟）

> 目的：剩下只有「必须由你本人点」的项目——真实引擎账号、真实交互手感。照下表走一遍，把不通过的项截图发我即可。
> 当前建议验收版本：`1.1.3-dev.14`（或发布前的最新 dev）。分支：`fix/1.1.3-prep`。

## A. 启动与权限（2 分钟）

| # | 操作 | 期望 | 记录 |
|---|---|---|---|
| A1 | 完全退出 Ein，再打开 | 不再弹「一念想控制此 Mac」；窗口正常出现 | ☐ |
| A2 | 打开 设置 → 电脑 | 若之前授权过：显示电脑控制可用；若没授权：出现「打开系统设置 / 重试」卡片（不自动弹权限窗） | ☐ |
| A3 | 在 A2 点「重试」 | 只有这时才会请求辅助功能/屏幕录制权限 | ☐ |

## B. 维护岗与构建卡（2 分钟）

| # | 操作 | 期望 | 记录 |
|---|---|---|---|
| B1 | 设置 → 维护岗 | 显示维护岗；源码 `~/Ein-src`、渠道 `开发版`、研发部「Ein 维护」在位 | ☐ |
| B2 | 看「构建与发布」 | 显示 verify 门槛说明；出现「从该分支构建的开发版版本会是 1.1.3-dev.N」；main 版本提示 | ☐ |
| B3 | 模型下拉 | 初始选中 = 维护机器人自己的模型（WorkBuddy · Deepseek-V4.1-Flash），不是 Grok | ☐ |
| B4 | 模型下拉展开 | 有 `云端`（GPT/Codex 系）与 `WorkBuddy`（全部 19 个模型，第一项 Deepseek-V4.1-Flash）两个分组 | ☐ |

## C. 聊天与插话（需要已登录的真实引擎，3–5 分钟）

| # | 操作 | 期望 | 记录 |
|---|---|---|---|
| C1 | 用 Claude 引擎让 Bot 写一段长文 | 流式输出顺滑、最后一行完整露在输入框上方 | ☐ |
| C2 | 选模型 → Claude | 能看到 Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 | ☐ |
| C3 | 用 Grok 聊一句后再选修模型 | 出现 Grok 4.7（以及账号可用新模型） | ☐ |
| C4 | 用 API Key 登录的 Claude Code | Claude 引擎显示「需要登录」并说明原因；不会拿 API Key 计费 | ☐ |
| C5 | Bot 干活时发一句插话（Codex / Grok） | 立即进入当前回合（不显示「已排队」），下一步模型能看到 | ☐ |
| C6 | 群聊里机器人在说话时发一句 | 支持插话的引擎立即进入；不支持的仍排队 | ☐ |
| C7 | pi / API 类引擎（Grok API、OpenAI 兼容、MiniMax）插话 | 当前回复结束后同一回合内续一次请求，只产生一个回复 | ☐ |
| C8 | 新建对话 / 切任务 | 新对话出现在左侧列表并自动滚到可见位置 | ☐ |

## D. 记忆与侧栏（1 分钟）

|---|---|---|---|

## E. 派单与协作（可选，需一点额度）

|---|---|---|---|

## F. 记录方式

- 不通过的项：编号 + 截图（或录屏）+ 当时的 Bot/引擎名；
- 崩溃/卡死：附 `~/Library/Logs/Ein/server.log` 与 `updater.log` 的最后 20 行；
- 全部通过后回复「验收通过」，即可进入正式版发布流程。
