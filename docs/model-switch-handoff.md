# 中途换模型：上下文怎么交接（设计稿）

> 2026-10-17 老板提出：工作过程中如果突然换模型（换便宜的，或觉得做得不好换贵的），新模型怎么对接上下文？直接承接全文，还是压缩交接？成本怎么控制？
> 结论：**换模型等于换人，交接用「结构化交接包」，不重放整段聊天记录。**

## 一、要回答的问题

1. 换模型后，新模型是直接承接原上下文，还是从零开始？
2. 上下文能不能高效衔接（不丢关键决策，也不把 token 烧在重放历史上）？
3. 换成贵的模型时，长上下文成本很高，怎么控制？

## 二、核心原则

- **不重放，只交接**：原始对话留在本地（可检索、可回看），新模型只拿一份「当前任务状态」；
- **交接包有预算**：默认 800–1500 tokens，绝不随对话长度线性增长；
- **先估算再切换**：切换前显示「将注入约 X tokens、预计花费 ¥Y」，老板确认才换；
- **验收标准不变**：换模型不改变对该任务/子任务的验收标准与验收人；
- **可回退**：换模型记入任务时间线；新模型连续不通过验收时，提示换回原模型。

## 三、按场景分三种

| 场景 | 做法 |
|---|---|
| 同一引擎内换模型（如 Claude Sonnet → Opus，session 兼容） | 可以复用会话；仍追加一份**短交接包**（目标/当前进度/上一步结论），保证换脑不丢方向 |
| 跨引擎 / 跨会话（Claude → Codex / WorkBuddy…） | 新会话 + **标准交接包**；原会话不重放；需要细节时由新模型主动检索 |
| 派单子任务中途换模型 | 只允许对「尚未开始」的子任务换；已开始的由原模型做完或明确中止后重试。重试的新模型拿到的本来就是员工提示词 + 验收标准 + 依赖结果（天然交接包），**不需要聊天记录** |

## 四、交接包里放什么（预算 ≈ 1200 tokens）

1. 任务宪法：目标、成功标准、**不做的事**、约束、截止、预算（≈300）；
2. 当前子任务：brief、边界、交付物、验收标准、验收人（≈400）；
3. 最新 Handoff：已完成/证据/关键决策（含理由）/未决问题/风险/下一步（≈300）；
4. 最近 1–2 条原文（只在语义必要时光滑过渡，≈200）；
5. 产出清单：文件路径、消息 ID（不塞内容，按需读取）。

**不放进来的**：完整对话、全部工具输出、全部历史结果、完整文档正文（用引用 ID/路径代替，需要时检索）。

## 五、成本控制（换成贵的模型时）

- **切换确认卡**：显示「原模型 → 新模型」「注入 tokens ≈」「预计本次花费 ≈¥」「本任务已花/预算」；
- 超预算或超过设定阈值（如单次注入 > 2000 tokens 或预估花费 > 预算 20%）时，默认不切换，提示先做阶段小结；
- 便宜模型换贵模型：优先「只交接、不重放」；确实需要更多细节时，让新模型通过检索工具按需拉取（按次计费、可审计）；
- 贵模型换便宜模型：允许略大一点的交接包（便宜），但同样设上限；
- **prompt cache 友好**：system/宪法等稳定前缀保持不变，便于新模型复用缓存。

## 六、UI 与留痕

- 模型切换入口：Bot 设置 / 子任务模型选择 / 工作台「换更强模型」；
- 切换前确认卡（含 token/费用估算）；切换后任务时间线记一条「模型切换」事件；
- 对话里保留原模型的历史消息（只读），新模型从交接包开始；
- 可查看「新模型这轮收到了什么」（交接包全文），便于审计「当时到底告诉它了什么」。

## 七、派单与任务负责人的配合

- 任务负责人决定换模型（或上报总控批准，超过预算线时）；
- 换模型不影响：验收标准、验收人、边界、已完成的交付物；
- 换模型后如果子任务失败/验收不过：退回到原模型或升级模型，并把失败原因写进 Handoff。

## 八、分阶段实现

| 阶段 | 内容 | 验收 |
|---|---|---|
| 1 | 交接包构建器（纯函数 + 单测）：从 run/subtask/复盘生成 ≤1200 token 的交接文本 | 同一个子任务重试用不同模型时，prompt 含完整交接包 |
| 2 | 聊天换模型确认卡：token/费用估算 + 确认后新会话注入交接包 | 换模型后新模型能答出「当前在做什么/下一步」，成本可见 |
| 3 | 检索工具：新模型可按需读取历史片段/产出文件（带引用） | 长对话下不重放也能拿到细节 |
| 4 | 指标：换模型前后的一次通过率、花费、耗时；不达标自动建议回退 | 有数据支撑「换得值不值」 |

## 九、风险

- 压缩过度导致丢关键信息 → 交接包字段固定（目标/决策/未决/下一步必须写全）；
- 便宜模型跟不上 → 验收标准不变，连续失败提示升级换回；
- token 估算不准 → 先用字符/4 估算，后续按引擎实际用量校准；
- 换模型打断正在跑的 turn → 只允许在「turn 结束后」或「子任务未开始」时切换，绝不中途切断。
